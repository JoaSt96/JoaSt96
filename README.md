### About me

I'm a frontend and mobile engineer from Buenos Aires, focused on architecture: the performance, releases, native code and design systems that let teams ship with confidence.

Today I'm part of the Architecture team at **Cocos**, responsible for the mobile app. Along the way I've led the frontend of an e-commerce startup across web and mobile, led a 13-person team taking a fintech wallet in-house, and helped raise the bar for mobile development at a healthcare company.

The full stories live at [stok.sobrado.tech](https://stok.sobrado.tech).
